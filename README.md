# marloes_test

React web applicatie met een klikbaar hartje. Klik op het hartje en het draait één keer om, waarna de tekst **"Ik hou van jou..."** verschijnt.

## Starten

```bash
npm install
npm run dev      # ontwikkelserver
npm test         # unittests (vitest)
npm run build    # productiebuild
```
